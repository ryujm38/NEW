# 택미린솔록면 — 아발론 · 우노

친구들이 각자 폰 브라우저로 접속해서 같이 하는 실시간 보드게임입니다. 첫 화면에서 **아발론(5~10명)**, **마피아(5~12명)**, **우노(2~10명)**, **뱅!(4~7명)**, **스플렌더(2~4명)**, **부루마블(2~6명)**, **보난자(3~5명)**, **라스베가스(3~6명)**, **세븐 원더스 듀얼(2명)** 중 하나 를 골라 방을 만듭니다. 앱 설치도, 회원가입도 없습니다.
한 명이 방을 만들고 4글자 코드(또는 초대 링크)를 보내면 나머지가 들어옵니다. 방 코드만으로 게임 종류가 정해집니다.

## 아발론 (5~10명)

| 인원 | 선 / 악 | 원정 인원 (1~5번째) | 4번째 원정 |
|---|---|---|---|
| 5명 | 3 / 2 | 2·3·2·3·3 | 실패 1장 |
| 6명 | 4 / 2 | 2·3·4·3·4 | 실패 1장 |
| 7명 | 4 / 3 | 2·3·3·4·4 | **실패 2장** |
| 8명 | 5 / 3 | 3·4·4·5·5 | **실패 2장** |
| 9명 | 6 / 3 | 3·4·4·5·5 | **실패 2장** |
| 10명 | 6 / 4 | 3·4·4·5·5 | **실패 2장** |

- 멀린, 퍼시벌, 모르가나, 암살자는 항상 들어가고, 남는 선 자리는 충성스러운 신하, 남는 악 자리는 악의 하수인이 채웁니다. 모드레드·오베론은 넣지 않았습니다.
- 5번 연속 부결 시 악 승리, 선이 3번 성공해도 암살자가 멀린을 맞히면 악 역전승
- 찬성이 과반이면 원정 출발, 동수는 부결
- 역할 배정·투표·카드는 모두 서버가 쥐고 있고, 각자에게는 볼 수 있는 정보만 보냅니다 (이번 판에 들어간 역할 목록은 모두에게 공개)
- 새로고침하거나 폰이 꺼졌다 켜져도 같은 방, 같은 역할로 자동 복귀합니다
- 방장은 게임 도중에도 ⚙ 방장 메뉴에서 "처음부터 다시 시작(역할 새로 배정)" 또는 "초기화하고 대기실로"를 고를 수 있습니다
- 음성은 없습니다. 토론은 디스코드나 카카오톡 보이스톡을 켜 놓고 하세요

## 마피아 (5~12명)

- 서버가 사회자 역할. 마피아 floor(n/3)명(최소 1), 경찰 1, 의사 1, 나머지는 시민.
- **진행 순서**: 역할 확인 → **1일차 낮**(토론·투표) → 1번째 밤 → 2일차 낮 → … 게임은 낮부터 시작합니다(1일차 낮에는 아직 밤사이 일어난 일이 없습니다).
- **밤**: 마피아는 함께 한 명을 지목(표가 갈리면 최다득표 중 무작위), 의사는 한 명을 보호(자기 자신 가능), 경찰은 한 명을 조사(본인만 마피아 여부 확인). 마피아의 표적을 의사가 지켰으면 아무도 죽지 않습니다.
- **낮**: 밤의 결과 공개 → 토론 → 산 사람의 **과반**이 "토론 끝"을 누르면 투표.
- **투표**: 각자 한 명(또는 기권). 단독 최다득표자가 **처형 후보**가 되고, 동률이면 아무도 후보가 되지 않습니다. 자기 자신에게는 투표할 수 없습니다.
- **찬반 투표**: 후보를 뺀 산 사람이 "처형(찬성)" 또는 "살리기(반대)"를 고릅니다. **찬성이 반대보다 많아야** 처형되고 동수면 삽니다. 후보 본인은 투표할 수 없고, 개표 전에는 남의 선택이 보이지 않으며(몇 명이 했는지만 보임), 개표 뒤에 모두 공개됩니다. 안 한 사람이 있으면 방장이 "기다리지 않고 개표"를 누를 수 있고 안 한 사람은 반대로 셉니다.
- **투표 기록**: 화면 아래 "📜 투표 기록" 버튼으로 낮마다 1차 투표(누가 누구에게)와 찬반 투표(찬성/반대한 사람, 결과)를 다시 볼 수 있습니다. 개표된 것만 기록되고, 죽은 사람도 볼 수 있습니다.
- 마피아가 모두 죽으면 시민팀, 마피아 수가 나머지 생존자 수 이상이면 마피아팀 승리.
- **채팅**: 낮/투표에는 산 사람 전체 채팅, 밤에는 마피아끼리만. 죽은 사람은 말할 수 없습니다. (음성 없이도 할 수 있게)
- 대기실에서 방장이 옵션을 켜고 끌 수 있습니다: "죽은 사람의 직업 공개"(기본 켜짐), "경찰에게 직업까지 알려주기"(기본 꺼짐: 경찰은 마피아 여부만 알고, 켜면 시민/의사/마피아 직업까지 알게 됩니다).
- 단순화한 점: 의사가 같은 사람을 연속으로 지켜도 되고, 직업별 특수 규칙(연인, 정치인 등)과 최후 변론은 없습니다.
- 자리를 비운 사람 때문에 멈추면 방장이 ⚙ 방장 메뉴에서 "멈춘 곳 넘기기"를 누를 수 있습니다.

## 스플렌더 (2~4명)

- 보석으로 카드를 사서 점수를 모읍니다. 산 카드는 영구 할인(보너스)이 되어 점점 비싼 카드를 살 수 있습니다.
- 내 차례에 하나만: ① 서로 다른 색 보석 3개 ② 같은 색 2개(그 색이 4개 이상일 때) ③ 카드 1장 예약(금 보석 1개, 최대 3장, 덱 맨 위도 가능) ④ 카드 구매(보너스만큼 할인, 모자라면 금으로).
- 보석은 10개를 넘으면 버립니다. 턴 끝에 조건이 맞는 귀족이 오면 +3점(여러 명이면 선택).
- 15점이 되면 그 라운드까지 진행하고 끝. 최고 점수가 승리, 동점이면 산 카드가 적은 사람.
- **카드 90장(1단계 40, 2단계 30, 3단계 20)과 귀족 10명은 원본 목록이 아니라 원본과 같은 구조(단계별 장수, 색별 보너스 균형, 점수 분포)로 만든 구성**입니다. 규칙은 공식과 같습니다.
- 남은 색이 3가지 미만이면 가능한 만큼만 가져올 수 있고, 할 수 있는 행동이 하나도 없을 때만 차례를 넘길 수 있습니다.

## 부루마블 (2~6명)

- 32칸 원형 보드(도시 20곳, 관광지 3곳, 황금열쇠 4곳, 시작/무인도/사회복지기금 수령·접수/우주여행). 돈 단위는 만원, 모두 300만으로 시작, 시작을 지나면 월급 20만.
- 빈 도시 구입 → 내 도시에 다시 도착하면 별장·빌딩·호텔 건설(통행료가 크게 오름) → 남의 도시는 통행료를 내고 호텔이 아니면 (땅+건물)의 2배로 **인수** 가능. 같은 색 도시를 모두 가지면 통행료 2배. 관광지는 개수에 따라 10→20→40.
- 더블이면 한 번 더, 3번 연속 더블이면 무인도. 무인도는 벌금 20만 / 탈출권 / 더블 / 3턴 대기로 탈출. 황금열쇠 16종, 우주여행(다음 차례에 원하는 칸으로 이동), 사회복지기금(접수에 낸 돈을 수령 칸 도착자가 가져감).
- 돈이 모자라면 땅을 팔아(투자한 값의 절반) 갚고, 못 갚으면 파산. 한 명만 남거나 방장이 정한 바퀴(무제한/20/30/50, 기본 30)가 지나면 자산(현금+땅·건물 값)이 가장 많은 사람이 승리.
- **도시 이름·가격·황금열쇠 내용은 원본 부루마블 목록이 아니라 비슷한 구조로 만든 구성**입니다.
- 보드 칸을 누르면 그 칸의 가격·통행료 표를 볼 수 있습니다.

## 보난자 (3~5명)

- 콩을 심고 수확해서 코인을 모으는 카드 게임. 코인이 가장 많은 사람이 승리.
- **손패 순서는 바꿀 수 없고**, 내 차례에 맨 앞 카드를 반드시 심습니다(원하면 두 번째도). 한 밭에는 한 종류의 콩만, 밭은 2개(코인 3개로 3번째 밭 구매).
- 내 차례에 카드 2장이 펼쳐지고, 펼친 카드와 내놓은 손패를 두고 **거래**합니다. 다른 사람이 줄 카드/받고 싶은 카드를 제안하면 차례인 사람이 수락합니다(다른 사람끼리는 거래 불가). 받은 카드와 거래하지 않은 펼친 카드는 모두 바로 심어야 하고, 그다음 덱에서 3장을 뽑습니다.
- 수확은 언제든 가능(밭을 누르기). 콩이 1개뿐인 밭은 다른 밭에 2개 이상 있으면 수확 불가. 콩 수에 따라 코인(빈오미터)을 받고 나머지는 버립니다.
- 덱이 3번째로 바닥나면 끝나고, 모두 밭을 수확해서 코인이 가장 많은 사람이 승리(동점이면 공동 우승). 3명이면 커피콩을 뺍니다.
- **콩 10종의 장수와 빈오미터는 제 기억에 의존한 원작 기준 값**이라 실제 카드와 조금 다를 수 있습니다. 자리를 비운 사람 때문에 멈추면 방장이 "대신 진행"을 누를 수 있습니다.

## 라스베가스 (3~6명)

- 주사위를 카지노에 놓아 지폐를 따는 게임. 4라운드 후 돈이 가장 많은 사람이 승리(동점이면 공동 우승).
- 카지노 6곳(1~6번)에 지폐가 합계 $50k 이상 깔립니다(지폐 54장 덱: $10k×6, 20k×8, 30k×8, 40k×6, 50k~90k×각 5~6장).
- 내 차례에 남은 주사위를 **모두 굴리고**, 나온 숫자 하나를 골라 그 숫자의 주사위를 **전부** 같은 번호의 카지노에 놓습니다(굴린 주사위는 모두에게 보입니다). 주사위를 다 놓으면 라운드 종료.
- 정산: 카지노마다 **주사위 수가 같은 사람끼리는 모두 상쇄**되고, 남은 사람이 많이 놓은 순서대로 큰 지폐부터 가져갑니다. 남는 지폐는 버립니다. 시작 플레이어는 라운드마다 한 칸씩 이동.
- 주사위는 5명 이하면 8개, 6명이면 6개씩(6인 때 개수는 제 선택). **2인용 변형(가상 플레이어 주사위)은 없습니다.** 지폐 구성은 제 기억 기준이라 실제 카드와 다를 수 있습니다.
- 자리를 비운 사람 때문에 멈추면 방장이 "대신 진행"을 누를 수 있습니다.

## 세븐 원더스 듀얼 (2명)

- 2명 전용 카드 게임. 3개 시대 동안 카드를 모아 도시를 키우고, 군사·과학으로 즉시 이기거나 점수로 이깁니다. 동전 7개씩 시작.
- **불가사의 고르기**: 12개 중 8개를 4개씩 두 번 보여 주고 1·2·2·1 순서로 골라 각자 4개를 갖습니다(마지막 한 장은 자동). 둘이 합쳐 7개가 지어지면 남은 불가사의는 사라집니다.
- **카드 가져오기**: 카드를 피라미드로 깔고(1시대는 아래가 넓고 2시대는 위가 넓은 모양, 3시대는 모래시계 모양), 다른 카드에 **가려지지 않은** 카드만 번갈아 하나씩 가져옵니다. 뒷면 카드는 위 카드를 치우면 뒤집힙니다(서버는 뒷면 카드의 정체를 보내지 않습니다). 가져온 카드로 ① 건물 짓기(연계 기호가 있으면 무료) ② 버리고 동전 `2 + 내 상업(노랑) 카드 수` ③ 불가사의 짓기(카드는 불가사의 밑에 깔림) 중 하나를 합니다. 노란 테두리 카드가 가져올 수 있는 카드이고, 카드를 누르면 설명과 내 비용이 보입니다.
- **자원 구입**: 모자란 자원은 은행에서 삽니다. 한 개당 `2 + 상대가 가진 같은 자원 수(원자재·제품 카드)`, 비축소/세관이 있으면 1. 자원을 골라 쓰는 카드(포럼·대상 숙소·일부 불가사의)와 진보 토큰 할인까지 반영해 **가장 싼 방법으로 자동 계산**합니다.
- **즉시 승리**: 군사 말이 상대 수도(±9)까지 밀리거나, 서로 다른 과학 기호 6종(법률 토큰 포함)을 모으면 바로 승리. 같은 과학 기호 카드가 2장이 되면 진보 토큰 1개를 얻습니다. 군사 말이 3칸/6칸을 넘으면 상대가 동전 2/5개를 한 번씩 잃습니다.
- **점수 승리**: 3시대가 끝나면 카드 승점 + 불가사의 + 진보 토큰 + 군사(말이 앞선 쪽: 1~2칸 2점, 3~5칸 5점, 6~8칸 10점) + 동전 3개당 1점. 동점이면 시민(파랑) 승점이 높은 쪽, 그것도 같으면 공동 우승.
- 새 시대의 시작 플레이어는 군사가 약한 쪽(말이 자기 쪽에 가까운 쪽)이 고릅니다. 말이 가운데면 마지막 카드를 가져간 사람이 고릅니다(이 동률 규칙은 제가 정한 것).
- 불가사의 12종(피라미드·대도서관·공중정원·키르쿠스 막시무스·콜로서스·파로스 등대·피레우스 항구·아피아 가도·마우솔레움·아르테미스 신전·제우스 상·스핑크스)과 진보 토큰 10종(농업·건축·경제·법률·석공술·수학·철학·전략·신학·도시계획), 길드 7종(3시대에 3장만 섞임)을 구현했습니다.
- **카드 73장·불가사의의 이름/비용/효과는 원작 목록이 아니라 비슷한 구조로 새로 만든 구성**입니다(과학 기호는 6종이 카드 2장씩). 연계(무료 건설) 관계도 제가 새로 짠 것이라 원작과 다릅니다.
- 자리를 비운 사람 때문에 멈추면 방장이 ⚙ 방장 메뉴에서 "대신 진행"을 누를 수 있습니다(카드 버리기 등 자동으로 한 수).

## 우노

- 2~10명, 108장. 7장씩 받고 같은 색/숫자/기호를 내거나 와일드를 냅니다. 낼 게 없으면 1장 뽑습니다.
- 뽑은 카드가 낼 수 있으면 바로 내거나 넘기고, 낼 수 없으면 자동으로 넘어갑니다.
- 스킵, 리버스(2명이면 스킵), +2, 와일드, 와일드 +4. +2/+4는 쌓을 수 없고, **와일드 +4는 지금 색 카드가 없을 때만** 낼 수 있습니다(도전 규칙 없음).
- 카드가 1장 남으면 "우노!" 버튼을 눌러야 하고, 안 누르면 다음 사람이 움직이기 전에 다른 사람이 "고발"해서 2장을 뽑게 합니다. 2장 남았을 때 미리 외쳐 둘 수도 있습니다.
- 먼저 손패를 비우면 그 판의 승리. 승수는 방에 쌓이고, 방장은 "한 판 더(승수 유지)" 또는 "대기실로(승수 초기화)"를 고를 수 있습니다.
- 시작 카드는 숫자 카드만 나오도록 다시 뽑습니다. 점수제(500점)는 없고 판 승수만 셉니다.
- 자리를 비운 사람 때문에 멈추면 방장이 ⚙ 방장 메뉴에서 그 차례를 넘길 수 있습니다.
- 카드를 한 번 탭하면 고르기, 같은 카드를 다시 탭하거나 "이 카드 내기"를 누르면 냅니다. 노랗게 빛나는 카드가 낼 수 있는 카드입니다.

## 뱅! (4~7명)

- 서부 총잡이 카드 게임 BANG!. 보안관·부보안관·무법자·배신자(정체 비밀, 보안관만 공개), 캐릭터 16종(각자 고유 능력), 카드 80장.
- 4명 보안관1·배신자1·무법자2 / 5명 +부보안관1 / 6명 +무법자1 / 7명 +부보안관1. 보안관은 체력 +1.
- 내 턴: 2장 뽑기 → 카드 내기 → 손패가 체력보다 많으면 버리고 턴 종료. 거리(머스탱·스코프·무기 사거리), 뱅!/빗나감!, 인디언!, 개틀링, 결투, 잡화점, 패닉!, 캣 발루, 감옥, 다이너마이트, 배럴, 죽기 직전 맥주, 탈락 보상(무법자 처치 3장, 보안관이 부보안관을 처치하면 카드 모두 버림)을 모두 구현했습니다.
- 단순화한 점: **배럴은 맞을 때 자동으로 사용**하고, **럭키 듀크는 더 좋은 쪽을 자동으로 고릅니다.** 카드의 무늬·숫자 배치는 원본과 다를 수 있습니다(전체 비율만 비슷). 3인 변형 규칙과 확장판 캐릭터는 없습니다.
- 카드를 한 번 탭하면 고르기(설명이 보임), 대상이 필요한 카드는 고른 뒤 목록에서 노란 테두리의 사람을 누릅니다. 노랗게 빛나는 카드가 지금 낼 수 있는 카드입니다.
- 자리를 비운 사람 때문에 멈추면 방장이 ⚙ 방장 메뉴에서 "대신 진행"을 누를 수 있습니다.

## 실행

```bash
cd avalon
npm install
npm start          # http://localhost:3000
npm test           # 규칙 테스트 + 실제 서버 통합 테스트
```

### 방법 1: 같은 와이파이에 모여 있을 때
서버를 켠 컴퓨터의 내부 IP로 접속합니다. 예: `http://192.168.0.12:3000`

### 방법 2: 각자 다른 곳에 있을 때 (인터넷 공개)
이 서버는 **계속 켜져 있는 Node 서버**가 필요합니다. Cloudflare Pages나 GitHub Pages 같은 정적 호스팅에는 올릴 수 없습니다.

**Render (무료 플랜 있음)**
1. render.com에서 GitHub 저장소를 연결해 New → Blueprint를 고르면 저장소 루트의 `render.yaml`을 읽습니다.
   (직접 만들려면 Web Service, Root Directory `avalon`, Build `npm install`, Start `npm start`)
2. 배포가 끝나면 나오는 `https://….onrender.com` 주소를 친구들에게 보냅니다.

주의: Render 무료 플랜은 15분 동안 접속이 없으면 잠들고, 다시 열 때 30~60초 걸립니다. 약속 시간 직전에 한 번 열어 두세요.
서버가 재시작되면 진행 중인 방은 사라집니다(방은 메모리에만 저장).

**임시로 내 컴퓨터를 열고 싶을 때**: `npm start` 후 `npx cloudflared tunnel --url http://localhost:3000` 같은 터널 도구를 쓰면 임시 공개 주소가 나옵니다.

| `uno.js` | 우노 규칙 엔진. 덱, 합법 수, 효과, 우노 고발, 사람별로 걸러진 상태(남의 손패는 장수만) |
| `mafia.js` | 마피아 규칙 엔진. 밤 행동, 낮 토론, 투표, 찬반 투표, 승리 판정, 채널별 채팅(전체/마피아)과 사람별로 걸러진 상태 |
| `splendor.js` | 스플렌더 규칙 엔진. 카드·귀족 생성, 보석/예약/구매, 보석 한도, 귀족, 종료 조건 |
| `marble.js` | 부루마블 규칙 엔진. 이동/더블/무인도, 구입·건설·인수·통행료, 황금열쇠, 빚·파산, 바퀴 수 종료 (테스트용 주사위 예약 훅 `rigged`) |
| `bohnanza.js` | 보난자 규칙 엔진. 심기/수확/밭 구매, 거래(내놓기·제안·수락), 덱 3번 소진 종료. 콩 정보는 `public/bohnanza-data.js` |
| `vegas.js` | 라스베가스 규칙 엔진. 지폐 덱, 굴리기/놓기, 동수 상쇄 정산, 4라운드 |
| `duel.js` | 세븐 원더스 듀얼 규칙 엔진. 피라미드 배치/가림, 비용·자원 구입 자동 계산, 연계, 불가사의·진보 토큰 효과, 군사·과학 즉시 승리, 점수 계산. 카드 정보는 `public/duel-data.js` |
| `bang.js` | 뱅! 규칙 엔진. 효과를 작업 목록(queue)으로 쌓고 사람의 선택이 필요한 곳에서만 멈춤(pending). 카드·캐릭터 정보는 `public/bang-data.js`(서버와 화면 공용) |

## 알아둘 점
- 방 코드를 아는 사람은 누구나 들어올 수 있습니다(로비에서 6명이 차면 닫힙니다). 방장은 로비에서 사람을 내보낼 수 있습니다.
- 접속이 끊긴 사람이 있어도 방장이 "기다리지 않고 넘어가기"로 진행할 수 있습니다. 투표·원정 카드는 끊긴 사람이 돌아와야 끝납니다.
- 확인된 것: 아발론 규칙 테스트 31개(5~10명 무작위 시뮬레이션 포함), 우노 규칙 테스트 20개(40판 무작위 시뮬레이션 포함), 뱅! 규칙 테스트 39개(4~7명 100판 무작위 시뮬레이션: 카드 80장 보존·상태 검사), 마피아 규칙 테스트 21개(5~12명 240판 무작위 시뮬레이션 포함), 서버 통합 테스트 10개, 390×844 폰 크기 브라우저로 아발론 한 라운드, 우노·뱅!·마피아 한 판을 끝까지. 아직 확인 못 한 것: 실제 폰(iOS Safari 등)과 실제 인터넷 배포.
