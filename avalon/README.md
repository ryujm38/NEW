# 택미린솔록면 — 아발론 · 우노

친구들이 각자 폰 브라우저로 접속해서 같이 하는 실시간 보드게임입니다. 첫 화면에서 **아발론(5~10명)**, **마피아(5~12명)**, **우노(2~10명)**, **뱅!(4~7명)** 중 하나 를 골라 방을 만듭니다. 앱 설치도, 회원가입도 없습니다.
한 명이 방을 만들고 4글자 코드(또는 초대 링크)를 보내면 나머지가 들어옵니다. 방 코드만으로 게임 종류가 정해집니다.

## 아발론 (5~10명)

| 인원 | 선 / 악 | 원정 인원 (1~5번째) | 4번째 원정 |
|---|---|---|---|
| 5명 | 3 / 2 | 2·3·2·3·3 | 실패 1장 |
| 6명 | 4 / 2 | 2·3·4·3·4 | 실패 1장 |
| 7명 | 4 / 3 | 2·3·3·4·4 | **실패 2장** |
| 8명 | 5 / 3 | 3·4·4·5·5 | **실패 2장** |
| 9명 | 6 / 3 | 3·4·4·5·5 | **실패 2장** |
| 10명 | 6 / 4 | 3·4·4·5·5 | **실패 2장** |

- 멀린, 퍼시벌, 모르가나, 암살자는 항상 들어가고, 남는 선 자리는 충성스러운 신하, 남는 악 자리는 악의 하수인이 채웁니다. 모드레드·오베론은 넣지 않았습니다.
- 5번 연속 부결 시 악 승리, 선이 3번 성공해도 암살자가 멀린을 맞히면 악 역전승
- 찬성이 과반이면 원정 출발, 동수는 부결
- 역할 배정·투표·카드는 모두 서버가 쥐고 있고, 각자에게는 볼 수 있는 정보만 보냅니다 (이번 판에 들어간 역할 목록은 모두에게 공개)
- 새로고침하거나 폰이 꺼졌다 켜져도 같은 방, 같은 역할로 자동 복귀합니다
- 방장은 게임 도중에도 ⚙ 방장 메뉴에서 "처음부터 다시 시작(역할 새로 배정)" 또는 "초기화하고 대기실로"를 고를 수 있습니다
- 음성은 없습니다. 토론은 디스코드나 카카오톡 보이스톡을 켜 놓고 하세요

## 마피아 (5~12명)

- 서버가 사회자 역할. 마피아 floor(n/3)명(최소 1), 경찰 1, 의사 1, 나머지는 시민.
- **밤**: 마피아는 함께 한 명을 지목(표가 갈리면 최다득표 중 무작위), 의사는 한 명을 보호(자기 자신 가능), 경찰은 한 명을 조사(본인만 마피아 여부 확인). 마피아의 표적을 의사가 지켰으면 아무도 죽지 않습니다.
- **낮**: 밤의 결과 공개 → 토론 → 산 사람의 **과반**이 "토론 끝"을 누르면 투표.
- **투표**: 각자 한 명(또는 기권). 단독 최다득표자가 처형되고, 동률이면 아무도 처형되지 않습니다. 자기 자신에게는 투표할 수 없습니다.
- 마피아가 모두 죽으면 시민팀, 마피아 수가 나머지 생존자 수 이상이면 마피아팀 승리.
- **채팅**: 낮/투표에는 산 사람 전체 채팅, 밤에는 마피아끼리만. 죽은 사람은 말할 수 없습니다. (음성 없이도 할 수 있게)
- 대기실에서 방장이 "죽은 사람의 직업 공개"를 켜고 끌 수 있습니다(기본 켜짐).
- 단순화한 점: 의사가 같은 사람을 연속으로 지켜도 되고, 직업별 특수 규칙(연인, 정치인 등)과 최후 변론은 없습니다.
- 자리를 비운 사람 때문에 멈추면 방장이 ⚙ 방장 메뉴에서 "멈춘 곳 넘기기"를 누를 수 있습니다.

## 우노

- 2~10명, 108장. 7장씩 받고 같은 색/숫자/기호를 내거나 와일드를 냅니다. 낼 게 없으면 1장 뽑습니다.
- 뽑은 카드가 낼 수 있으면 바로 내거나 넘기고, 낼 수 없으면 자동으로 넘어갑니다.
- 스킵, 리버스(2명이면 스킵), +2, 와일드, 와일드 +4. +2/+4는 쌓을 수 없고, **와일드 +4는 지금 색 카드가 없을 때만** 낼 수 있습니다(도전 규칙 없음).
- 카드가 1장 남으면 "우노!" 버튼을 눌러야 하고, 안 누르면 다음 사람이 움직이기 전에 다른 사람이 "고발"해서 2장을 뽑게 합니다. 2장 남았을 때 미리 외쳐 둘 수도 있습니다.
- 먼저 손패를 비우면 그 판의 승리. 승수는 방에 쌓이고, 방장은 "한 판 더(승수 유지)" 또는 "대기실로(승수 초기화)"를 고를 수 있습니다.
- 시작 카드는 숫자 카드만 나오도록 다시 뽑습니다. 점수제(500점)는 없고 판 승수만 셉니다.
- 자리를 비운 사람 때문에 멈추면 방장이 ⚙ 방장 메뉴에서 그 차례를 넘길 수 있습니다.
- 카드를 한 번 탭하면 고르기, 같은 카드를 다시 탭하거나 "이 카드 내기"를 누르면 냅니다. 노랗게 빛나는 카드가 낼 수 있는 카드입니다.

## 뱅! (4~7명)

- 서부 총잡이 카드 게임 BANG!. 보안관·부보안관·무법자·배신자(정체 비밀, 보안관만 공개), 캐릭터 16종(각자 고유 능력), 카드 80장.
- 4명 보안관1·배신자1·무법자2 / 5명 +부보안관1 / 6명 +무법자1 / 7명 +부보안관1. 보안관은 체력 +1.
- 내 턴: 2장 뽑기 → 카드 내기 → 손패가 체력보다 많으면 버리고 턴 종료. 거리(머스탱·스코프·무기 사거리), 뱅!/빗나감!, 인디언!, 개틀링, 결투, 잡화점, 패닉!, 캣 발루, 감옥, 다이너마이트, 배럴, 죽기 직전 맥주, 탈락 보상(무법자 처치 3장, 보안관이 부보안관을 처치하면 카드 모두 버림)을 모두 구현했습니다.
- 단순화한 점: **배럴은 맞을 때 자동으로 사용**하고, **럭키 듀크는 더 좋은 쪽을 자동으로 고릅니다.** 카드의 무늬·숫자 배치는 원본과 다를 수 있습니다(전체 비율만 비슷). 3인 변형 규칙과 확장판 캐릭터는 없습니다.
- 카드를 한 번 탭하면 고르기(설명이 보임), 대상이 필요한 카드는 고른 뒤 목록에서 노란 테두리의 사람을 누릅니다. 노랗게 빛나는 카드가 지금 낼 수 있는 카드입니다.
- 자리를 비운 사람 때문에 멈추면 방장이 ⚙ 방장 메뉴에서 "대신 진행"을 누를 수 있습니다.

## 실행

```bash
cd avalon
npm install
npm start          # http://localhost:3000
npm test           # 규칙 테스트 + 실제 서버 통합 테스트
```

### 방법 1: 같은 와이파이에 모여 있을 때
서버를 켠 컴퓨터의 내부 IP로 접속합니다. 예: `http://192.168.0.12:3000`

### 방법 2: 각자 다른 곳에 있을 때 (인터넷 공개)
이 서버는 **계속 켜져 있는 Node 서버**가 필요합니다. Cloudflare Pages나 GitHub Pages 같은 정적 호스팅에는 올릴 수 없습니다.

**Render (무료 플랜 있음)**
1. render.com에서 GitHub 저장소를 연결해 New → Blueprint를 고르면 저장소 루트의 `render.yaml`을 읽습니다.
   (직접 만들려면 Web Service, Root Directory `avalon`, Build `npm install`, Start `npm start`)
2. 배포가 끝나면 나오는 `https://….onrender.com` 주소를 친구들에게 보냅니다.

주의: Render 무료 플랜은 15분 동안 접속이 없으면 잠들고, 다시 열 때 30~60초 걸립니다. 약속 시간 직전에 한 번 열어 두세요.
서버가 재시작되면 진행 중인 방은 사라집니다(방은 메모리에만 저장).

**임시로 내 컴퓨터를 열고 싶을 때**: `npm start` 후 `npx cloudflared tunnel --url http://localhost:3000` 같은 터널 도구를 쓰면 임시 공개 주소가 나옵니다.

## 구조

| 파일 | 역할 |
|---|---|
| `game.js` | 아발론 규칙 엔진(순수 로직). 역할 배정, 투표, 원정, 암살, 사람별로 걸러진 상태 |
| `uno.js` | 우노 규칙 엔진. 덱, 합법 수, 효과, 우노 고발, 사람별로 걸러진 상태(남의 손패는 장수만) |
| `mafia.js` | 마피아 규칙 엔진. 밤 행동, 낮 토론, 투표, 승리 판정, 채널별 채팅(전체/마피아)과 사람별로 걸러진 상태 |
| `bang.js` | 뱅! 규칙 엔진. 효과를 작업 목록(queue)으로 쌓고 사람의 선택이 필요한 곳에서만 멈춤(pending). 카드·캐릭터 정보는 `public/bang-data.js`(서버와 화면 공용) |
| `common.js` | 두 게임이 같이 쓰는 도우미 |
| `server.js` | 정적 파일 + WebSocket. 방 생성/입장/재접속, 연결 유지(ping). 방 종류에 맞는 엔진의 `actions` 표로 요청을 전달 |
| `public/` | 폰 화면(빌드 없는 HTML/CSS/JS). `app.js` 공통·아발론, `uno.js` 우노, `bang.js` 뱅!, `mafia.js` 마피아 |
| `test/` | `game.test.js` 아발론 규칙, `uno.test.js` 우노 규칙, `bang.test.js` 뱅! 규칙, `mafia.test.js` 마피아 규칙, `server.test.js` 실제 서버에 접속해 한 판 |

## 알아둘 점
- 방 코드를 아는 사람은 누구나 들어올 수 있습니다(로비에서 6명이 차면 닫힙니다). 방장은 로비에서 사람을 내보낼 수 있습니다.
- 접속이 끊긴 사람이 있어도 방장이 "기다리지 않고 넘어가기"로 진행할 수 있습니다. 투표·원정 카드는 끊긴 사람이 돌아와야 끝납니다.
- 확인된 것: 아발론 규칙 테스트 31개(5~10명 무작위 시뮬레이션 포함), 우노 규칙 테스트 20개(40판 무작위 시뮬레이션 포함), 뱅! 규칙 테스트 39개(4~7명 100판 무작위 시뮬레이션: 카드 80장 보존·상태 검사), 마피아 규칙 테스트 21개(5~12명 240판 무작위 시뮬레이션 포함), 서버 통합 테스트 10개, 390×844 폰 크기 브라우저로 아발론 한 라운드, 우노·뱅!·마피아 한 판을 끝까지. 아직 확인 못 한 것: 실제 폰(iOS Safari 등)과 실제 인터넷 배포.
