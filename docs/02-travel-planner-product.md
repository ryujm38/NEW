# 여행 플래너 — 제품 방향과 MVP (v1)

작성일: 2026-10-12 · 작성: Claude(모루) · 결정: 망치(당신)

`01-saas-idea-research.md`의 후보 5개 대신, 망치가 **여행 계획 플래너**로 방향을 정했습니다. 그리고 앱스토어용 네이티브 앱이 아니라 **반응형 웹**으로 가기로 했습니다.

## 1. 결정 사항

| 항목 | 결정 | 이유 |
|---|---|---|
| 형태 | 반응형 웹 + PWA(홈 화면 추가) | 앱스토어 심사·수수료 없이 폰·태블릿·PC를 한 코드로. 링크 하나로 공유 가능 |
| 스택 | React + TypeScript + Vite | 가볍고 배포가 쉬움. 나중에 서버를 붙여도 그대로 확장 가능 |
| 데이터 | 우선 기기 내 localStorage | 계정·서버 없이 가장 빨리 써 보게 하려는 것. **동기화는 다음 단계** |
| 언어·지도 | 한국어 우선, 네이버/구글 지도 링크 | 한국어 사용자 기준의 가설. 아래 "검증 안 된 것" 참고 |

> 가정: 목표 시장을 아직 못 들었습니다. 한국어 사용자 기준으로 시작했고, 아니라면 알려 주세요.

## 2. 경쟁 현황 (2차 자료, 방향성만)

- **Wanderlog:** 지도 기반 계획과 그룹 협업이 강점. 무료는 장소 무제한과 실시간 협업, Pro(연 $39.99부터)에서 오프라인·경로 최적화·Gmail 자동 스캔.
- **TripIt:** 예약 확인 메일을 일정으로 바꿔 주는 것이 강점. Pro는 연 $49.
- **Stippl:** AI 일정 생성과 예산이 있고 프리미엄은 연 €24.99. 신생이라 초기 사용자의 동기화·충돌 불만이 있음.

**사용자 불만으로 반복해서 보인 것** (앱 리뷰 요약 사이트 기준, 유료 보고서가 섞여 있음):
- 일정이 길면 느려지고, 온보딩이 복잡하다
- 오프라인이 유료
- 월 단위 요금이 없고 연 결제만 있다
- 일정 순서 바꾸기와 예산 관리가 불편하다
- 계획한 뒤 길 찾기를 하려면 지도 앱에 다시 입력해야 한다

→ 시장은 이미 차 있습니다. **"여행 계획 앱이 없어서"가 아니라 "기존 앱이 불편해서"가 우리가 파고들 틈**입니다.

## 3. 우리의 차별화 가설 (아직 검증 전)

1. **가볍고 빠름:** 로그인 없이 바로 시작. 긴 일정에서도 느려지지 않기
2. **오프라인 무료:** 서비스 워커로 이미 동작함(브라우저에서 확인함)
3. **예산이 기본 기능:** 일정에 비용을 적으면 일차별·전체 합계와 초과 경고가 자동으로
4. **계획 → 이동 연결:** 장소별 지도 링크로 길 찾기까지 한 번에
5. **한국어·국내 지도 우선:** 네이버 지도 연동(현재는 검색 링크, 이후 장소 검색 API)

## 4. 지금 만든 것

`app/` 폴더. 실행 방법과 기능 목록은 `app/README.md` 참고.

**검증한 것**
- 단위 테스트 25개 통과 (날짜 계산, 윤일·월 경계, 순서 변경, 시간순 정렬, 예산 합계, 저장 데이터 검증, 공유 텍스트)
- 린트, 타입 검사, 프로덕션 빌드 통과
- 실제 브라우저(390px 폰, 1280px PC)에서 여행 생성 → 일정 추가 → 정렬 → 예산 표시 → 새로고침 후 유지, 가로 스크롤 없음, 콘솔 에러 없음
- 네트워크를 끈 상태에서 새로고침해도 앱이 열림

**검증하지 못한 것**
- 실제 폰(iOS Safari, 안드로이드 Chrome)에서의 동작과 홈 화면 설치. 데스크톱 Chromium에서만 확인함
- 공유 시트(`navigator.share`)는 데스크톱에서 클립보드 복사 경로만 확인함
- 접근성은 라벨과 포커스 표시를 신경 썼지만 스크린리더로는 확인 못 함
- 실제 사용자 반응. 아직 아무도 써 보지 않음

## 5. 다음 단계 제안

| 순서 | 할 일 | 이유 |
|---|---|---|
| 1 | **배포하고 지인 5~10명에게 써 보게 하기** (Cloudflare Pages나 Vercel, 무료) | 가설 1~5 중 무엇이 실제로 먹히는지 가장 싸게 확인 |
| 2 | PWA용 PNG 아이콘 만들기, 앱 이름·로고 정하기 | 배포 전 필수 |
| 3 | 계정 + 서버 동기화 + 공유 링크(그룹 여행) | 경쟁 앱 대비 필수 기능. 서버 선택(예: Supabase)이 필요한 결정 |
| 4 | 장소 검색 자동완성과 좌표(네이버/카카오 지도 API) | 계획 → 이동 연결을 제대로 구현 |
| 5 | AI 일정 초안 | 유료 기능 후보. 비용 구조를 먼저 계산해야 함 |

## 6. 수익 모델 (초안, 검증 필요)

- **무료:** 여행 계획 전부(오프라인 포함)
- **유료 후보:** 기기 간 동기화, 여러 명이 함께 편집, AI 일정 초안, 예약 메일 가져오기
- 경쟁사가 연 $24~49이고 "월 결제가 없다"는 불만이 있으니 **월 결제 옵션**을 차별점으로 삼는 것도 검증해 볼 만합니다.
- 숫자는 아직 없습니다. 1단계에서 사용자 반응을 본 뒤 정합니다.
